# ربات هوش مصنوعی تلگرام (DeepSeek)

یک ربات تلگرامی ساده و بهینه که با استفاده از مدل‌های DeepSeek به سوالات کاربران پاسخ می‌دهد.
DeepSeek یک API سازگار با فرمت OpenAI دارد، پس ربات از کتابخانه‌ی رسمی `openai` با آدرس پایه‌ی متفاوت استفاده می‌کند.

## ویژگی‌ها

- **پاسخ استریم (پله‌پله)**: به‌جای صبر برای کل پاسخ، پیام تلگرام به‌مرور کامل می‌شود — حس سرعت بالا به کاربر می‌دهد.
- **کاملاً Async**: چند کاربر همزمان می‌توانند بدون بلاک شدن ربات با آن کار کنند.
- **حافظه‌ی مکالمه محدود**: فقط چند پیام آخر هر کاربر نگه‌داری می‌شود تا درخواست‌ها سبک، ارزان و سریع بمانند.
- **محدودیت نرخ درخواست (Rate limit)** ساده برای جلوگیری از اسپم.
- **مدیریت خطا** برای مشکلات شبکه یا API.

## پیش‌نیازها

- Python 3.10 یا بالاتر
- یک توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather))
- یک کلید API از [platform.deepseek.com](https://platform.deepseek.com)

## نصب و راه‌اندازی

1. فایل‌ها را در یک پوشه قرار دهید.

2. یک محیط مجازی بسازید (اختیاری ولی توصیه‌شده):
   ```bash
   python3 -m venv venv
   source venv/bin/activate   # در ویندوز: venv\Scripts\activate
   ```

3. وابستگی‌ها را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```

4. فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید، سپس مقادیر را پر کنید:
   ```bash
   cp .env.example .env
   ```
   و داخل آن:
   ```
   TELEGRAM_BOT_TOKEN=توکن_ربات_شما
   DEEPSEEK_API_KEY=کلید_API_دیپ‌سیک_شما
   ```

5. ربات را اجرا کنید:
   ```bash
   python bot.py
   ```

اگر همه چیز درست باشد، در ترمینال پیام «ربات در حال اجراست...» را می‌بینید. حالا می‌توانید در تلگرام به ربات پیام بدهید.

## دستورات ربات

- `/start` — شروع و پاک کردن حافظه‌ی مکالمه
- `/reset` — پاک کردن تاریخچه‌ی مکالمه
- `/help` — راهنما

## تنظیمات قابل تغییر (در فایل `.env`)

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `MODEL_NAME` | نام مدل DeepSeek؛ `deepseek-chat` (سریع، عمومی) یا `deepseek-reasoner` (استدلال عمیق‌تر) | `deepseek-chat` |
| `DEEPSEEK_BASE_URL` | آدرس پایه‌ی API دیپ‌سیک | `https://api.deepseek.com` |
| `MAX_HISTORY_MESSAGES` | تعداد پیام‌های اخیر نگه‌داری‌شده برای هر کاربر | `12` |
| `MAX_OUTPUT_TOKENS` | حداکثر طول پاسخ مدل | `1024` |
| `STREAM_EDIT_INTERVAL` | فاصله زمانی (ثانیه) بین ویرایش‌های پیام در حال استریم | `0.7` |
| `MIN_SECONDS_BETWEEN_REQUESTS` | حداقل فاصله بین دو درخواست هر کاربر | `1.0` |

## نکات برای اجرای دائمی (Production)

- برای اجرای ۲۴ ساعته، ربات را با ابزاری مثل `systemd`، `pm2`، یا داخل یک کانتینر Docker اجرا کنید تا در صورت کرش، خودکار دوباره بالا بیاید.
- اگر تعداد کاربران زیاد شد، به‌جای نگه‌داری حافظه‌ی مکالمه در RAM (دیکشنری پایتون)، از Redis یا یک دیتابیس سبک استفاده کنید تا با ری‌استارت شدن برنامه، مکالمات از دست نروند.
- می‌توانید به‌جای Polling (`run_polling`) از Webhook استفاده کنید تا تاخیر کمتر و مصرف منابع بهینه‌تری داشته باشید، به‌خصوص روی سرورهایی با ترافیک بالا.
- کلید API را هرگز داخل کد قرار ندهید؛ همیشه از متغیرهای محیطی (`.env`) استفاده کنید.

## عیب‌یابی

- **خطای `Unauthorized`**: توکن تلگرام اشتباه است.
- **خطای احراز هویت DeepSeek (401)**: کلید API اشتباه، منقضی یا بدون اعتبار کافی است.
- **ربات پاسخ نمی‌دهد**: مطمئن شوید که فرآیند `python bot.py` در حال اجراست و به اینترنت دسترسی دارد.
